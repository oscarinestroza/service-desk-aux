    Columnas esperadas en el archivo

    El sistema detecta automáticamente las columnas por su nombre (insensible a mayúsculas/minúsculas). La columna Institución es la única obligatoria.

    Columnas
    • Institución — Nombre completo (obligatorio)
    • Abreviatura / Siglas
    • Unidad Funcional / Edificio
    • Estado (ACTIVO / INACTIVO)
    Comportamiento
    • Si la siglas ya existen, se actualiza la institución
    • Si el nombre ya existe, se actualiza la institución
    • Si no existe, se crea automáticamente
    • Si el edificio no existe, se crea automáticamente
    • Estado vacío se asume como ACTIVO
